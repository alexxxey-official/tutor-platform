# Отчёт о разработке: Интерактивный Банк Заданий ЕГЭ по профильной математике (2026-08-01)

## Описание изменений
Реализован полнофункциональный банк заданий и конструктор вариантов ЕГЭ по профильной математике (задания № 1–19).

### 1. Рендеринг формул KaTeX (`MathText.js`)
- Создан реактовский компонент `MathText`, поддерживающий парсинг инлайн `$ ... $` и блочных `$$ ... $$` LaTeX-формул.
- Подключен глобальный стилистический модуль KaTeX (`katex/dist/katex.min.css`).

### 2. База данных задач ЕГЭ (`ege-math-bank.js`)
- Реализована база реальных задач ЕГЭ 2024–2026 по номерам:
  - **Часть 1 (#1–11):** Планиметрия, стереометрия, вероятность (простая и сложная), простейшие уравнения, вычисления и тригонометрия, производная, прикладные формулы, текстовые задачи, графики функций, экстремумы.
  - **Часть 2 (#12–18):** Тригонометрические уравнения с отбором корней, стереометрия, неравенства методом рационализации, финансовая математика, планиметрия, задачи с параметром, теория чисел.
- Включены пошаговые KaTeX-решения, критерии, краткие и альтернативные ответы.
- Реализована функция `calculateScores()` для пересчета первичных баллов в 100-балльную шкалу ЕГЭ.

### 3. Главная страница банка и конструктор (`/math-bank/page.js`)
- Удобная фильтрация по номеру задания (#1–18), сложности («Базовый», «Средний», «Профиль») и текстовому поиску.
- Быстрый выбор готовых пресетов: «Собрать вариант 2026», «Часть 1 (#1-11)», «Часть 2 (#12-18)».
- Плавающая панель снизу с живым счетчиком выбранных задач и кнопками запуска теста или генерации печатных файлов.

### 4. Интерактивный режим теста (`/math-bank/test/page.js`)
- Таймер 3ч 55мин с возможностью паузы/завершения.
- Ввод кратких ответов для 1-й части с автопроверкой.
- Самопроверка решения по критериям для 2-й части.
- Итоговый экраном со 100-балльным эквивалентом и разбором ошибок.

### 5. Двухрежимный печатный модуль (`/math-bank/print/page.js`)
- **Версия для ученика:** КИМ с местом для заметок, бланком ответов №1 и местом под задачи 2-й части.
- **Версия для учителя:** КИМ с пошаговыми KaTeX-решениями, критериями и ответами.
- Полная адаптация под диалог печати браузера (`Cmd+P` / `Ctrl+P`) через `@media print`.
