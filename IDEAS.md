# 💡 Банк Идей (Idea Bank)

Здесь хранятся все крутые задумки, фичи и предложения, которые мы решили отложить на будущее, чтобы не потерять фокус.

## Интеграции & Инфраструктура
- [ ] **Telegram Бот для Администратора:** Создать бота (Node.js/Telegraf), подключенного к Supabase, для отправки пуш-уведомлений о прогрессе учеников (например: "Иван прошел Passive Voice на 90%") и быстрого мониторинга состояния платформы без входа в веб-версию.
- [ ] **Email уведомления ученикам:** Отправлять email когда преподаватель назначает новый урок или когда ученик прошёл урок на 100%.
- [ ] **Экспорт статистики:** Выгрузка прогресса всех учеников в CSV/Excel для отчётов.

## UI/UX & Платформа
- [ ] **Тёмная тема:** Добавить переключатель тёмной/светлой темы на дашборде.
- [ ] **Мобильное приложение:** Обернуть в PWA или Capacitor для доступа с телефона.
- [ ] **Страница профиля ученика:** Настройки аккаунта, смена пароля, аватар.
- [ ] **Рейтинг учеников:** Таблица лидеров по предметам (геймификация).

## Контент & Геймификация
- [ ] **Ачивки/Бейджи:** "Первый урок", "5 уроков подряд", "100% по испанскому" и т.д.
- [ ] **Серия дней (Streak):** Отслеживание непрерывных дней занятий.
- [ ] **Аудио в уроках:** Web Speech API для произношения слов и фраз.
- [ ] **Таймер Pomodoro:** Встроенный таймер для времени занятий.
- [ ] **Сравнение прогресса:** "Ты прошёл 3 урока за неделю — лучше 70% учеников!"

## Админ-панель
- [ ] **Массовое назначение уроков:** Назначать урок нескольким ученикам сразу.
- [ ] **Журнал активности:** Лог действий админа (кого назначил, когда, какой урок).
- [ ] **Уведомления в реальном времени:** WebSocket для обновления прогресса без перезагрузки.
